# BenchScout WWW submission snapshot

This snapshot was compiled from `main.tex` with `latexmk -pdf -interaction=nonstopmode -halt-on-error`.
The current PDF has 12 pages: eight pages of main content, one references page,
and three appendix pages. The main text includes the audited four-session
CloudSuite curve analysis and the coordinate-specific Web compression pipeline;
isolated FPM4 pairs are exploratory and concurrent stress sessions are reported
separately with their validity conditions. The appendix marks the supplied GPU
values as provenance because M6 run-level records are not retained.

The manuscript is double blind. Reproduction scripts and raw run records are
distributed separately in the artifact bundle; no author identity is added to
this submission snapshot.
