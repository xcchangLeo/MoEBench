# Round 4 Independent Review

## Recommendation

**Reject (2/5), confidence 4/5.** The new diagnostic fixes a real training/inference feature-construction mismatch in the reconstructor protocol, but the corrected OOF predictions are exactly unchanged and the paper's core evidence still does not establish a benefit from learned probe routing or generalization beyond one session.

## New Diagnostic Audit

- `scripts/run_corrected_oof_unixbench.py` builds outer-fold reconstructor training inputs from probe predictions generated by inner leave-one-run-out probe models. Each target training run is excluded from the probe fit used to generate its training features. Outer held-out runs are excluded from the outer probe fit, reconstructor fit, and fold-local router fit.
- The five crossfit reports cover five outer folds for each of five machines. Their fold manifests show disjoint inner probe-fit and prediction runs, with every inner prediction run drawn from the outer training runs. Probe dataset and run artifact hashes match the files in the workspace.
- Independent comparison against the prior run-level OOF reports found exact equality for all 25 held-out suite predictions and relative errors. Across the 25 reports, mean error is 0.590448%, median 0.210306%, P95 3.653039%, and maximum 4.715528%. The unchanged outputs are consistent with the previously observed suite head relying on xi features rather than probe inputs; this diagnostic itself does not prove why predictions stayed unchanged.
- The diagnostic therefore addresses the specific oracle-score versus probe-predicted-score mismatch in reconstructor training inputs. It does not turn the run-level folds into independent-session evaluation: all runs remain from one session per host, and inner probe models are trained on one fewer run than the outer inference probe model.

## Continuing Blocking Findings

1. **No independent generalization test.** Each host-suite pair still has one collection session and five runs. Random run-level folds cannot establish session, temporal, configuration, or cross-host generalization. Model and Top-K choices also lack a locked external test.

2. **No demonstrated value from learned routing or probe inputs.** Learned Top-3 and three fixed Top-3 strategies still produce identical suite predictions on all 25 runs despite selecting different probes. Fold-matched xi-only mean error remains 0.608% versus 0.590% for the policy pipeline, a small and inconsistent difference. The new crossfit run-level errors are exactly unchanged. The representative M5 fold still has zero probe-feature split gain and unchanged output after 10% perturbations, though this sensitivity evidence covers only one fold.

3. **Baseline comparison remains weak.** The table's Wang-style DNN and Tousi-style MLP are correctly labeled as local proxies, not reproductions. The selected Tousi MLP proxy has 98.85% GPU error while available RF, decision-tree, and elastic-net variants are around 0.26%. Execution-free baselines use same-host leave-one-run-out and static features, not a new-host setting.

4. **Primary timing evidence remains partly unauditable.** GPU reported-cost semantics are disclosed, but CPU full-suite cells still lack per-cell run identifiers, aggregation statistics, and a consistent elapsed-time definition. OOF UnixBench profile-time sums are not suite elapsed time; live traces remain one run per host, omit context collection from BenchScout time, and are separate from accuracy evaluation.

5. **Reproduction remains incomplete.** The submission archive lacks raw data, checkpoints, complete split manifests, and a complete portable table-generation path. Absolute machine-specific paths remain in experiment artifacts. PTS is still a paper-defined log-mean proxy, not an official PTS aggregate.

## Evidence Needed for Reconsideration

- Independent session, temporal, configuration, or host holdout, with model and Top-K selection completed before evaluation on the locked holdout.
- Fold- and session-replicated sensitivity analyses showing whether probes and routing improve over xi-only reconstruction and fixed subsets.
- Traceable per-cell timing sources with a consistent elapsed-time definition and repeated timing runs.
- Competitive baselines evaluated with the same split and precisely named model variants.
- A portable artifact bundle with raw data or stable access, checkpoints/configuration, split membership, environment details, and table-generation commands.
