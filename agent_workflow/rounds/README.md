Each review round gets a directory here (for example `round-0/`) containing
the immutable snapshot hash, independent review, modifier plan, patch, build
log, protocol audit log, and final re-review. Do not overwrite an earlier
round; append a new round when the loop continues.

Round 1 also includes leakage-controlled UnixBench OOF reports for all five
hosts and the independent review in `round-1/review.md`.
